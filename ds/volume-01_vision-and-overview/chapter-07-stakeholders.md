# Chapter 7: Stakeholders

The ecosystem is designed for multiple groups, each with distinct interests and contributions.

## 7.1 End Users

**Interest:** a seamless, adaptive, private interaction experience.

- Wear whatever modules suit their needs and budget.
- Applications adapt automatically to their hardware.
- Sensitive data stays private by default.
- No vendor lock-in for hardware or apps.

## 7.2 Hardware Manufacturers

**Interest:** build interoperable modules using open specifications.

- Follow the Universal Module Standard (Volume III) to reach the whole ecosystem.
- Publish capabilities instead of proprietary APIs.
- Compete on quality, price, and innovation rather than closed ecosystems.
- Certify products to signal compliance (Volume X).

## 7.3 Application Developers

**Interest:** write once, run across any valid mesh.

- Target capabilities and intents, never hardware.
- Rely on the Application Framework for adaptive UI, context, and AI (Volume IX).
- One SDK instead of per-vendor SDKs.
- Distribute through open app and capability marketplaces.

## 7.4 Researchers & Innovators

**Interest:** prototype new interaction techniques and modalities.

- Add experimental capabilities, recognizers, and AI models.
- Publish new interaction patterns to the Interaction Registry.
- Build reference hardware without negotiating with incumbents.

## 7.5 Enterprises & Integrators

**Interest:** deploy in industrial, medical, productivity, and automotive settings.

- Standardized compliance profiles (Core, Enterprise, Industrial, Medical) reduce procurement risk.
- Centralized governance, fleet diagnostics, and OTA updates (Volumes IV, X).
- Privacy and audit controls satisfy regulatory requirements.

## 7.6 Standards Bodies & Foundations

**Interest:** long-term stewardship of the platform.

- Governance model (Volume X) separates specification, implementation, and certification.
- Community processes ensure transparent, consensus-based evolution.
- Ecosystem registries maintain interoperability over time.

## 7.7 Summary of Interests

| Stakeholder | Primary Value |
|-------------|---------------|
| End Users | Seamless, private, adaptive experience |
| Hardware Makers | Open interoperable module market |
| App Developers | Write once, run everywhere |
| Researchers | Open platform for novel interaction |
| Enterprises | Compliance, fleet control, privacy |
| Standards Bodies | Durable, governed open standard |
