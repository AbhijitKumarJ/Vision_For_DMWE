# Chapter 17: Human Factors & Ergonomics

**Volume VI — Human Interaction Framework (HIF) · Working Draft v0.1**

Incorporates principles from ergonomics and cognitive psychology.

## 17.1 Factors

| Factor | Description |
|--------|-------------|
| Cognitive load | Mental effort per interaction |
| Interaction fatigue | Physical/mental exhaustion |
| Learnability | Ease of acquiring interactions |
| Discoverability | Ease of finding capabilities |
| Muscle memory | Consistent, repeatable inputs |
| Error prevention | Design to avoid mistakes |
| Interaction consistency | Same intent, same result |
| Spatial ergonomics | Comfortable reach/motion |
| Attention management | Respect user focus |

## 17.2 Design Guidance

- **Cognitive load:** reduce steps, offer defaults, use context.
- **Fatigue:** distribute load across modalities; frequent interactions use low-effort expressions.
- **Learnability:** consistent mappings (Chapter 6); progressive disclosure.
- **Discoverability:** discoverable shortcuts (help on demand).
- **Muscle memory:** stable mappings; avoid arbitrary changes.
- **Error prevention:** confirm high-impact actions; forgiving defaults.
- **Consistency:** identical semantics across apps.
- **Spatial ergonomics:** reachable gestures; avoid awkward poses.
- **Attention:** don't interrupt flow; ambient feedback for background tasks.

## 17.3 Comfort Under Prolonged Use

- Prefer low-effort, low-fatigue expressions for frequent actions.
- Provide rest postures for sustained interactions.
- Monitor for fatigue and offer alternatives (Chapter 11).

## 17.4 Evaluation

- Interactions are evaluated for: task time, error rate, effort, satisfaction.
- Results feed the user profile and QoC (Volume V, Ch 11).

## 17.5 Conformance

A conformant implementation SHOULD apply these factors in interaction design and evaluation.
