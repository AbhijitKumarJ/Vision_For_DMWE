# Chapter 17: Mobility & Travel

**Volume XII — Reference Applications · Working Draft v0.1**

## 17.1 HUD Assist

**Problem:** Eyes on the road, full control.

- **Capabilities:** `Gesture`, `Spatial Audio`, `Vehicle Integration`.
- **Grammar:** Ring gestures on steering-wheel cover → Accept ride / Navigate.
- **Context:** Driving mode (safety filters applied).
- **Experience:** Eyes on the road, full control.

## 17.2 Omni-View

**Problem:** Third-person awareness in high-risk activity.

- **Capabilities:** `Drone / Camera`, `Retinal Projection`.
- **Grammar:** Toss micro-drone bead → Activate third-person view.
- **Context:** Skiing / high-risk activity.
- **Experience:** See yourself and hazards from above in real time.

## 17.3 Mobility Requirements

- Driving mode MUST apply safety filters (Volume VI, Ch 15).
- Vehicle integration follows the Automotive profile (Volume X, Ch 18).
- High-risk contexts require reliable communication (Volume VIII, Ch 12).

## 17.4 Common Patterns

- Spatial audio replaces visual output while driving.
- Drone integration extends sensing.
- Safety gating is mandatory.

## 17.5 Conformance

These applications demonstrate conformant mobility patterns: safety-filtered interaction and augmented awareness.
