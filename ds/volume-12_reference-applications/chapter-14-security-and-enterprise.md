# Chapter 14: Security & Enterprise

**Volume XII — Reference Applications · Working Draft v0.1**

## 14.1 Ghost Desk

**Problem:** Turning any surface into a workstation.

- **Capabilities:** `Air Typing`, `Gesture`, `Projection`.
- **Grammar:** Finger taps on table (acoustic + EMG fusion) → Text input.
- **Context:** "Work" mode + flat surface detected.
- **Fusion:** EMG Wrist + optional table vibration sensors + AR glasses.
- **Experience:** Type at 100+ WPM on any desk; a holographic monitor appears.

## 14.2 Enterprise Requirements

- Enterprise deployment follows the Enterprise profile (Volume X, Ch 5).
- Managed policies apply (Volume IX, Ch 15).
- Audit trails are maintained (Volume VII, Ch 15).

## 14.3 Common Patterns

- Fusion creates virtual input surfaces.
- Projection creates persistent workspaces (Volume IX, Ch 10).
- Context detects work mode.

## 14.4 Conformance

This application demonstrates conformant enterprise patterns: virtual input and projected workspaces.
