# Chapter 4: Productivity & Remote Work

**Volume XII — Reference Applications · Working Draft v0.1**

## 4.1 Spatial Presenter

**Problem:** Present naturally without being tied to a keyboard or mouse.

- **Capabilities:** `Precision Pointer`, `Selection`, `Gesture`, `Semantic Navigation`.
- **Grammar:**
  - `Point` + `Continuous` + `Screen` → laser pointer overlay.
  - `Swipe_Right` (air) → `Next_Slide`.
  - `Tight_Fist` (EMG) → `Mute_Unmute`.
- **Context:** "Presentation" mode (calendar + app focus + standing posture).
- **Fusion & Flow:** Ring IMU + UWB Necklace (spatial anchor) + optional eye tracking → fused `Precision Pointer`. Compute Bead runs classifier. Intent Packet sent to laptop IBN.
- **Minimal Hardware:** Smart Ring + Phone.
- **Enhanced:** + Projector Beads for local holographic notes.
- **Experience:** Stand, gesture freely, maintain eye contact. System auto-adapts if modules change.

## 4.2 Macro Mesh

**Problem:** Complex shortcuts break flow when hands are on mouse/stylus.

- **Capabilities:** `Continuous Scalar`, `Rotate`, `Gesture`.
- **Grammar:** `Pinch_Twist` (non-dominant) → `Rotate Canvas`; `Thumb_Slide` → `Brush_Size`.
- **Context:** Design app active + non-dominant hand resting.
- **Fusion:** Ring + Wrist EMG + optional Smart Pocket.
- **Experience:** Two-handed workflow in free space. Left hand operates macros while the right hand draws.

## 4.3 Common Patterns

- Semantic navigation replaces hotkeys.
- Non-dominant hand controls macros.
- Context gates mode (presentation vs design).
- Minimal and enhanced hardware tiers are supported.

## 4.4 Conformance

These applications demonstrate conformant productivity patterns: intent-first, context-gated, and hardware-independent.
