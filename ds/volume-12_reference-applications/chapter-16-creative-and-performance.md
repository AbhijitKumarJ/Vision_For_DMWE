# Chapter 16: Creative & Performance

**Volume XII — Reference Applications · Working Draft v0.1**

## 16.1 Invisible Stream Deck

**Problem:** Full studio control without breaking gameplay flow.

- **Capabilities:** `Foot Gesture`, `Head Tracking`.
- **Grammar:** `Right Foot Tap` (x2) → Camera switch; `Head Tilt` → Soundboard.
- **Context:** Gaming/streaming (hands occupied).
- **Experience:** Full studio control without breaking flow.

## 16.2 Lucid Construct

**Problem:** Instant spatial sandbox for co-creation.

- **Capabilities:** `Neural Intent`, `Projection`, `Collaborative`.
- **Grammar:** Thought + micro-gesture → "Render castle here."
- **Context:** Public park + creative mode.
- **Experience:** Co-create shared holographic worlds with passers-by who join your mesh.

## 16.3 Performance Requirements

- Hands-occupied contexts use feet and head input.
- Shared creation follows multi-user mesh rules (Volume VII, Ch 14).
- Projection follows the spatial framework (Volume IX, Ch 10).

## 16.4 Common Patterns

- Non-hand modalities extend control.
- Collaborative spaces support co-creation.
- Neural intent is privacy-gated.

## 16.5 Conformance

These applications demonstrate conformant performance patterns: alternative modalities and shared creation.
