# Chapter 5: Daily Utility & Media

**Volume XII — Reference Applications · Working Draft v0.1**

## 5.1 Messy Mode

**Problem:** Hands wet, greasy, or occupied.

- **Capabilities:** `Semantic Gesture`, `Head Tracking`.
- **Grammar:** `Double_Nod` → `Skip`; `Thumb_Flick_Up` → `Scroll_Next`.
- **Context:** Kitchen/workshop detected (motion + environmental sensors).
- **MeshOS:** Disables fine touch, prioritizes robust gestures.
- **Experience:** Control media without touching devices.

## 5.2 Invisible Wayfinder

**Problem:** Dangerous phone-glancing while walking.

- **Capabilities:** `Haptic Output`, `Spatial Audio`, `Localization`.
- **Grammar:** System-generated directional pulses + whispered audio cues.
- **Context:** Walking + navigation active.
- **Fusion:** Wrist/ankle haptics + earbuds. Digital Twin tracks body orientation.
- **Experience:** Eyes-free, perfect navigation.

## 5.3 Common Patterns

- Modality substitution based on context.
- Haptic and audio output replace visual output.
- Motion and environmental sensors gate behavior.

## 5.4 Conformance

These applications demonstrate conformant utility patterns: robust gestures, eyes-free output, and context-gated interaction.
