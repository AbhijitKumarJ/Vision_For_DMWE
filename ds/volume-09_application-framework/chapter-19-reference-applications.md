# Chapter 19: Reference Applications

**Volume IX — Application Framework & Runtime Specification (AFRS) · Working Draft v0.1**

## 19.1 Purpose

Illustrative examples demonstrate architecture, capability usage, interaction flows, and deployment patterns.

## 19.2 Reference Applications

- Personal productivity assistant.
- Spatial note-taking.
- Collaborative whiteboard.
- Navigation assistant.
- Industrial inspection.
- Medical monitoring.
- Fitness coaching.
- Smart home control.

## 19.3 Personal Productivity Assistant

- **Intents:** summarize meeting, manage calendar, dictate notes.
- **Capabilities:** speech, generation, scheduling.
- **Deployment:** edge hub + ring.
- **Interactions:** voice + gesture.

## 19.4 Spatial Note-Taking

- **Intents:** place note in space, retrieve by position.
- **Capabilities:** spatial anchors, projection.
- **Deployment:** glasses + projection module.
- **Interactions:** gaze + gesture.

## 19.5 Collaborative Whiteboard

- **Intents:** share canvas, annotate together.
- **Capabilities:** shared workspace, presence (Volume VII, Ch 14).
- **Deployment:** multiple users, shared spaces.
- **Interactions:** multimodal.

## 19.6 Navigation Assistant

- **Intents:** guide user to destination.
- **Capabilities:** location, haptics, audio.
- **Deployment:** phone hub + wrist modules.
- **Interactions:** haptic + audio feedback.

## 19.7 Industrial Inspection

- **Intents:** inspect equipment, flag defects.
- **Capabilities:** vision, AI inference, reporting.
- **Deployment:** industrial profile (Volume VIII, Ch 18).
- **Interactions:** hand gesture + voice.

## 19.8 Medical Monitoring

- **Intents:** monitor vitals, alert caregivers.
- **Capabilities:** biosensors, telemetry, alerts.
- **Deployment:** medical profile, audit-focused.
- **Interactions:** ambient, hands-free.

## 19.9 Fitness Coaching

- **Intents:** track activity, coach form.
- **Capabilities:** motion sensors, AI coaching.
- **Deployment:** wrist + headphones.
- **Interactions:** audio + haptic.

## 19.10 Smart Home Control

- **Intents:** control room environment.
- **Capabilities:** intermediary bridges (Volume I, Ch 8).
- **Deployment:** controller + hub.
- **Interactions:** pointing + gesture.

## 19.11 Conformance

Reference applications are illustrative; they demonstrate conformant patterns but are not prescriptive.
