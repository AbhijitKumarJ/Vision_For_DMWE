# Chapter 18: Reference Profiles

**Volume X — Ecosystem Governance, Compliance & Certification (EGCC) · Working Draft v0.1**

Defines standardized deployment profiles. Each profile references applicable requirements from the previous volumes.

## 18.10 Profile Requirements

- Each profile references applicable requirements.
- Requirements map to source volumes.
- Profiles MAY overlap.

## 18.11 Conformance

A conformant deployment MUST declare a profile and meet its referenced requirements.
