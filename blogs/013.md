## Request

Build the "MeshOS Node Simulator"

## Response

Here is a functioning **MeshOS Node Simulator** written in TypeScript. 

This simulator brings the specifications to life. It simulates the wireless medium (BLE/UWB), a Smart Ring joining the mesh, the MeshOS Coordinator (Primary Node) registering capabilities, and a Developer Application subscribing to semantic intents.

You can save this code as `simulator.ts` and run it locally using Node.js (via `npx ts-node simulator.ts`).

### The MeshOS Node Simulator (`simulator.ts`)

```typescript
import { EventEmitter } from 'events';

// ============================================================================
// 1. SCHEMAS & TYPES (From Volume XI)
// ============================================================================

enum PayloadType { DESCRIPTOR, CAPABILITY_ADVERT, INTERACTION_OBJ }
enum Verb { SELECT = "SELECT", MOVE = "MOVE", ROTATE = "ROTATE" }
enum Target { CURRENT_OBJECT = "CURRENT_OBJECT", IOT_DEVICE = "IOT_DEVICE" }

interface MeshEnvelope {
    messageId: string;
    senderId: string;
    payloadType: PayloadType;
    payload: any;
}

interface CapabilityAdvertisement {
    capabilityId: string;
    version: string;
    qoc: { latencyMs: number; accuracyScore: number };
}

interface InteractionObject {
    interactionId: string;
    intent: { verb: Verb; target: Target };
    origin: { capabilityId: string; providerId: string };
    confidence: number;
}

// ============================================================================
// 2. THE TRANSPORT LAYER (Volume VIII - Simulating the "Air")
// ============================================================================

class MeshRadio extends EventEmitter {
    broadcast(packet: MeshEnvelope) {
        // Simulate wireless transmission delay (e.g., 5ms BLE latency)
        setTimeout(() => {
            this.emit('rx_packet', packet);
        }, 5);
    }
}
const localRadio = new MeshRadio();

// ============================================================================
// 3. PHYSICAL MODULES (Volume III - e.g., A Smart Ring)
// ============================================================================

class SmartRingNode {
    public nodeId = "DMWE-RNG-9942";

    constructor(private radio: MeshRadio) {}

    public boot() {
        console.log(`\n💍 [RING] Powering on. Running secure boot...`);
        
        // Step 1: Module Discovery Protocol (MDP)
        this.radio.broadcast({
            messageId: `msg-${Date.now()}-1`,
            senderId: this.nodeId,
            payloadType: PayloadType.DESCRIPTOR,
            payload: { manufacturer: "DMWE Labs", deviceClass: "SENSOR_NODE" }
        });

        // Step 2: Capability Exchange Protocol (CEP)
        const capAdvert: CapabilityAdvertisement = {
            capabilityId: "interaction.pointer.precision",
            version: "1.0",
            qoc: { latencyMs: 8, accuracyScore: 0.98 }
        };
        this.radio.broadcast({
            messageId: `msg-${Date.now()}-2`,
            senderId: this.nodeId,
            payloadType: PayloadType.CAPABILITY_ADVERT,
            payload: capAdvert
        });
    }

    // Simulate user performing a physical gesture (e.g., air pinch)
    public simulateAirPinch() {
        console.log(`\n👆 [RING] User performed physical 'Air Pinch' gesture.`);
        
        // Translating raw sensor data to Semantic Intent (Volume VI)
        const interaction: InteractionObject = {
            interactionId: `ix-${Date.now()}`,
            intent: { verb: Verb.SELECT, target: Target.IOT_DEVICE },
            origin: { capabilityId: "interaction.pointer.precision", providerId: this.nodeId },
            confidence: 0.95
        };

        this.radio.broadcast({
            messageId: `msg-${Date.now()}-3`,
            senderId: this.nodeId,
            payloadType: PayloadType.INTERACTION_OBJ,
            payload: interaction
        });
    }
}

// ============================================================================
// 4. MESH OS COORDINATOR (Volume IV - e.g., running on a Phone or Hub)
// ============================================================================

class MeshOSPrimary {
    private capabilityRegistry: any[] = [];
    private appSubscriptions: Array<{ verb: Verb, callback: Function }> = [];

    constructor(private radio: MeshRadio) {
        this.radio.on('rx_packet', (packet: MeshEnvelope) => this.handlePacket(packet));
        console.log(`🧠 [MESH OS] Coordinator online. Listening to radio...`);
    }

    private handlePacket(packet: MeshEnvelope) {
        switch (packet.payloadType) {
            case PayloadType.DESCRIPTOR:
                console.log(`📡 [MESH OS] Discovered new module: ${packet.senderId} (${packet.payload.deviceClass})`);
                break;
                
            case PayloadType.CAPABILITY_ADVERT:
                this.capabilityRegistry.push({ provider: packet.senderId, ...packet.payload });
                console.log(`⚙️  [MESH OS] Registered Capability: '${packet.payload.capabilityId}' from ${packet.senderId}`);
                break;

            case PayloadType.INTERACTION_OBJ:
                console.log(`⚡ [MESH OS] Intent Engine received Interaction: [${packet.payload.intent.verb} -> ${packet.payload.intent.target}] (Confidence: ${packet.payload.confidence})`);
                this.routeToApps(packet.payload);
                break;
        }
    }

    // SDK exposure for applications
    public subscribeToIntent(verb: Verb, callback: Function) {
        this.appSubscriptions.push({ verb, callback });
    }

    private routeToApps(interaction: InteractionObject) {
        this.appSubscriptions.forEach(sub => {
            if (sub.verb === interaction.intent.verb) {
                sub.callback(interaction);
            }
        });
    }
}

// ============================================================================
// 5. THE DEVELOPER APPLICATION (Volume IX - Intent-Oriented Programming)
// ============================================================================

function startSmartHomeApp(meshOS: MeshOSPrimary) {
    console.log(`\n📱 [APP] Smart Home App launching...`);
    console.log(`📱 [APP] Subscribing to semantic 'SELECT' intents for IoT Devices...`);

    // The App doesn't care if it's a Ring, Glasses, or Neural implant.
    // It only cares about the Semantic Intent.
    meshOS.subscribeToIntent(Verb.SELECT, (interaction: InteractionObject) => {
        if (interaction.intent.target === Target.IOT_DEVICE) {
            console.log(`\n💡 [APP TRIGGERED] Turning ON the Smart Lamp!`);
            console.log(`   (Triggered by capability: ${interaction.origin.capabilityId} with ${interaction.confidence * 100}% confidence)`);
        }
    });
}

// ============================================================================
// 6. RUN THE SIMULATION
// ============================================================================

async function runSimulation() {
    console.log("==========================================");
    console.log("   DMWE MeshOS Initialization Sequence    ");
    console.log("==========================================\n");

    // 1. Initialize the Mesh (Phone/Hub boots up)
    const meshOS = new MeshOSPrimary(localRadio);
    
    // 2. Launch the Application
    startSmartHomeApp(meshOS);

    // 3. User puts on their Smart Ring
    const myRing = new SmartRingNode(localRadio);
    myRing.boot();

    // 4. Wait for mesh to form, then user gestures at a smart lamp
    setTimeout(() => {
        myRing.simulateAirPinch();
    }, 100);
}

runSimulation();
```

### What this simulation proves:

1. **Hardware Abstraction (Volume I & II):** Look at the Application code (Section 5). There is no mention of `Ring`, `Bluetooth`, or `Pinch`. The app strictly uses **Intent-Oriented Programming (IOP)**.
2. **Mesh Formation (Volume IV & VIII):** When the ring calls `boot()`, it simulates the `Module Discovery Protocol (MDP)` and `Capability Exchange Protocol (CEP)`. You can watch the MeshOS registry dynamically absorb the hardware.
3. **Semantic Intent Delivery (Volume VI):** The physical "Air Pinch" is translated by the ring into a standardized `InteractionObject` with a Confidence Score, proving the separation of physical gesture from semantic meaning.
