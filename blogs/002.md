## Request

now let us define mapping convention for each of our targeted candidates so that the input is successfully transmitted and converted via a mapper software or hardware circuit into well defined set of usable inputs/interaction endpoints available to application developer.  Group the response from developer app sdk interaction interface perspective where each interaction type is mapped to the preprocessed inputs from various controllers(raw inputs converted to standard specification of interaction type with mandatory and non mandatory fields ).

## Response

Here is the mapping convention grouped by the **Developer SDK Interaction Interface**, defining how raw controller data is preprocessed into standard, actionable endpoints.

### 1. Spatial/Pointer Interaction (`onPointerMove`)
**Purpose:** Cursor control, 3D spatial aiming, gaze targeting.
*   **Standard Interface Fields:**
    *   *Mandatory:* `x`, `y` (coordinates or deltas).
    *   *Optional:* `z` (depth), `velocity`, `confidenceScore`.
*   **Controller Mappings (Raw to Standard):**
    *   **Smart Contacts / Glasses:** Raw pupil IR reflection $\rightarrow$ Gaze Vector preprocessor $\rightarrow$ `x, y` screen coordinates.
    *   **Smart Ring (IMU):** Raw Gyro/Accel $\rightarrow$ Spatial fusion filter $\rightarrow$ `x, y, z` relative delta vectors.
    *   **Smart Pocket (E-Textile):** Raw capacitive grid array $\rightarrow$ Touch centroid preprocessor $\rightarrow$ `x, y` trackpad coordinates.

### 2. Discrete Action/Trigger (`onAction`)
**Purpose:** Clicks, selections, confirmations, fire commands.
*   **Standard Interface Fields:**
    *   *Mandatory:* `actionId` (e.g., primary_click, secondary_click, back).
    *   *Optional:* `pressure` (0.0 to 1.0), `duration` (milliseconds).
*   **Controller Mappings:**
    *   **EMG Wristband / Epidermal:** Raw neuromuscular spike $\rightarrow$ Machine Learning (ML) gesture classifier $\rightarrow$ `actionId` (e.g., thumb-index pinch = primary_click).
    *   **Hearables:** Raw jaw bone conduction/audio $\rightarrow$ Acoustic threshold filter $\rightarrow$ `actionId` (teeth-click = primary_click).
    *   **Ear-EEG:** Raw brainwave (P300 signal) $\rightarrow$ Intent classifier $\rightarrow$ `actionId` (focus threshold = select).

### 3. Continuous Scalar Input (`onScalarChange`)
**Purpose:** Scrolling, zooming, scrubbing timelines, volume control.
*   **Standard Interface Fields:**
    *   *Mandatory:* `delta` (value change).
    *   *Optional:* `axis` (X, Y, or Z), `accelerationRate`.
*   **Controller Mappings:**
    *   **Smart Ring:** Raw capacitive linear slide $\rightarrow$ Smoothing algorithm $\rightarrow$ `delta` (Y-axis scroll).
    *   **Smart Glasses:** Raw frame capacitive swipe $\rightarrow$ Directional processor $\rightarrow$ `delta` (X-axis timeline scrub).
    *   **EMG Wristband:** Raw muscle tension gradient $\rightarrow$ Proportional mapping $\rightarrow$ `delta` (continuous zoom).

### 4. Text/String Input (`onTextInput`)
**Purpose:** Dictation, silent commands, air-typing.
*   **Standard Interface Fields:**
    *   *Mandatory:* `stringValue`, `isFinal` (boolean for live transcription).
    *   *Optional:* `alternatives` (array of fallback strings), `confidenceLevel`.
*   **Controller Mappings:**
    *   **Subvocalization Patch:** Raw throat EMG $\rightarrow$ Local NLP sequence model $\rightarrow$ `stringValue` (silent speech to text).
    *   **Hearables (Mic):** Raw audio $\rightarrow$ Speech-to-Text API $\rightarrow$ `stringValue`.
    *   **EMG Wristband:** Raw multi-finger micro-twitches $\rightarrow$ QWERTY kinematic modeler $\rightarrow$ `stringValue` (air-typing).

### 5. Semantic Gesture & State (`onSemanticGesture`)
**Purpose:** High-level navigation (next/prev), system toggles, attention states.
*   **Standard Interface Fields:**
    *   *Mandatory:* `gestureType` (enum: swipe_left, nod, shake, focus).
    *   *Optional:* `phase` (start, active, end), `intensity`.
*   **Controller Mappings:**
    *   **Hearables (IMU):** Raw accelerometer data $\rightarrow$ Head-motion classifier $\rightarrow$ `gestureType` (nod = accept, shake = reject).
    *   **Ear-EEG / Smart Contacts:** Raw alpha/beta waves or Blink rate $\rightarrow$ Cognitive load preprocessor $\rightarrow$ `gestureType` (state = focused or distracted, pauses UI).
    *   **Smart Pockets:** Raw multi-thread capacitive swipe $\rightarrow$ Multi-touch preprocessor $\rightarrow$ `gestureType` (two-finger swipe_left = previous page).
